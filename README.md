Biccas - Productivity Landing Page

A modern and responsive SaaS landing page inspired by a Figma design.
This project is built using HTML, CSS, JavaScript, and Bootstrap 5 with smooth animations, interactive pricing cards, and a clean UI.

🚀 Features
Responsive Navbar
Hero Section with modern layout
Smooth Scroll Navigation
Interactive Pricing Toggle (Monthly / Yearly)
Scroll Reveal Animations
Benefit List Animation
CTA Section
Fully Responsive Design
Bootstrap 5 Integration
Modern UI inspired by Figma
🛠️ Technologies Used
HTML5
CSS3
JavaScript (Vanilla JS)
Bootstrap 5
Bootstrap Icons
Google Fonts
