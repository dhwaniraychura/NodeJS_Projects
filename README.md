# HTML to Node.js Conversion Project

This project demonstrates the conversion of a static HTML-based application into a dynamic Node.js application.

## 🚀 Project Overview

The main goal of this project was to transform traditional HTML pages into a server-side rendered application using Node.js. This allows better scalability, routing control, and backend integration.

## 🔧 Technologies Used

- Node.js
- Express.js
- HTML5
- CSS3
- JavaScript

## 📁 Project Structure
corona-node/
│
├── public/ # Static files (CSS, JS, images)
├── views/ # HTML pages converted to templates/routes
├── routes/ # Application routes
├── app.js # Main server file
├── package.json # Project dependencies

## ⚙️ Features

- Converted static HTML pages into Node.js routes
- Implemented Express server
- Organized project into MVC-like structure
- Served static files using Express middleware
- Improved scalability and maintainability
